## 三項必要排版規則

### 中文句子使用全形標點

```text
這不僅僅是把一張座位預約表搬到線上,更是一次...
→
這次調整把座位預約從紙本登記和人工喊號移到線上，也改變...
```

原稿中的中文半形逗號和句點均已處理，改寫版排版掃描為 0。

### 英文句子保留半形標點

```text
Service remains available，contact the library desk。
→
Service remains available, contact the library desk.
```

這個段落未放在程式碼保護區，因此確實觸發英文半形標點規則。

### 中英文之間使用一個半形空白

```text
SeatFlow系統
→
SeatFlow 系統
```

改寫版重新掃描後沒有缺少或重複的中英文交界空白。

## 用語與結構調整

用語掃描器在原稿找到 auto 14、flag 12，改寫版均為 0。主要處理包括：

- 軟件 → 軟體
- 隊列 → 佇列
- 數據 → 資料
- 默認 → 預設
- 性能 → 效能
- 響應時間 → 回應時間
- 配置 → 設定
- 回滾 → 還原
- 反饋 → 回饋
- 運行 → 執行

選定的 17 處 AI 寫作模式也已清除，包括「在當今……的時代」「不僅僅是」「眾所周知」「核心抓手」「沉澱最佳實踐」「充分說明」「值得注意的是」「不是……而是……」「總而言之」「護城河」與「未來可期」。

## 保真回讀

驗證腳本抽出 92 個數字 token，逐一比較值與出現次數。第一次驗證曾發現改寫版最後一段額外重複「6 週」，使數字 `6` 比原稿多一次；即使事實沒有矛盾，仍不符合逐項保真門檻，因此移除重複數字後才重新通過。

人工回讀另外確認：

- 未把同期指標變化改寫成 SeatFlow 造成的因果結果。
- 保留期中考、兩次暴雨、版本修正及操作熟悉度等限制。
- 保留截圖事件沒有外部公開、沒有發現完整號碼被下載的範圍。
- 保留館員對個別讀者情況的最終判斷權。
- 沒有替館員、讀者或團隊新增原稿不存在的故事、動機或立場。
- 刪除「會議室安靜下來」等沒有可核對資訊的戲劇化反應，但保留事件、處理措施和時程影響。
