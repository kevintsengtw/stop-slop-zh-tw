# 要避免的結構

## 二元對比

製造假張力。直接講重點。

| 模式 | 問題 |
|------|------|
| 「不僅僅是 X，更是 Y」 | AI 最愛的遞進，多半是湊字 |
| 「不是 X，而是 Y」 | 公式化的翻轉 |
| 「X 從來都不是問題，Y 才是」 | 套版重構 |
| 「答案不在 X，而在 Y」 | 可預測的轉折 |
| 「表面上是 X，實際上是 Y」 | 鋪陳／揭曉的陳腔 |
| 「真正的問題不是 X，是 Y」 | 修辭式誤導 |
| 「與其說是 X，不如說是 Y」 | 機械式對比 |

**改法：** 直接講 Y。「問題在 Y。」把整個否定句拿掉。

## 排比堆疊

三句結構相同的句子連發，是 AI 製造氣勢的招牌（對應英文的 rule of three）。

| 模式 | 問題 |
|------|------|
| 「它能 A，能 B，能 C」 | 三連排比湊氣勢 |
| 「是 X，是 Y，更是 Z」 | 遞進排比 |
| 四字成語連發（「高瞻遠矚、運籌帷幄、決勝千里」） | 成語當填充料 |

**改法：** 留一兩項最有力的，砍掉其餘。兩項勝過三項。

## 戲劇性斷句

為了「深刻感」把句子切碎。

| 模式 | 問題 |
|------|------|
| 「就這樣。沒了。這就是全部。」 | 表演式的簡潔 |
| 「一個字。X。」 | 人工高潮 |
| 「而這。改變了一切。」 | 假揭示 |

**改法：** 完整的句子。內容自己會說話，不需要靠斷句撐。

## 修辭式鋪陳

宣告洞見，而不是給出洞見。

| 模式 | 問題 |
|------|------|
| 「如果我告訴你 X，你會怎麼想？」 | 蘇格拉底式擺拍 |
| 「這裡的關鍵在於：」 | 多餘的預告 |
| 「想像一下：」 | 制式開場 |
| 「你可能會問：」 | 自問自答的套路 |
| 「而這，沒問題。」 | 不必要的許可 |

**改法：** 直接講。讓讀者自己下結論。

## 僵化骨架

| 模式 | 問題 |
|------|------|
| 「首先…其次…再者…最後…」整段套用 | 制式大綱，讀起來像 AI 在填表 |
| 「第一點…第二點…第三點…」過度編號 | 該用散文時硬切清單 |
| 每段開頭都「那麼，」「所以說，」 | 連接詞當拐杖 |

**改法：** 用內容本身的邏輯帶段落，不要每段靠序數詞起頭。

## 假主詞（無生命做人事）

把人類動作安到沒生命的東西上。AI 愛這樣，因為可以不用指名是誰。

| 模式 | 問題 |
|------|------|
| 「數據告訴我們」 | 數據不會說話，是你讀出來的 |
| 「市場獎勵了 X」 | 市場不獎勵，是買家付錢買 X |
| 「技術重新定義了 X」 | 是某些人用技術做了 X |
| 「時代呼喚 X」 | 沒有人在呼喚，是某群人需要 X |
| 「歷史證明」 | 是哪段史實、誰的研究？ |

**改法：** 原文有行動者時就指名，例如「團隊那週修好了」勝過「問題自己被解決了」。原文沒寫是誰，不要自行補成「我」或「你」；改成能由原文支持的中性句，或標示待作者補充。

## 旁白腔（站在遠處俯瞰）

飄在場景上方說教，而不是把讀者帶進去。

| 模式 | 問題 |
|------|------|
| 「人們往往會…」 | 扶手椅社會學家 |
| 「這是因為…」 | 講師腔 |
| 「這就是為什麼…」 | 同上 |
| 「在這個世界上，總有…」 | 假宏觀 |

**改法：** 原文已提供具體場景時，把場景寫出來。「打開專案時，測試全部失敗」勝過「人們常常面臨測試失敗的困境」。沒有場景就不要為了生動自行編造。

## 被動語態

每句都該有主詞在做事。被動句藏住做事的人，也抽掉力道。中文還常出現西化被動（「被進行」「被給予」）。

| 模式 | 改法 |
|------|------|
| 「X 被建立了」 | 指名是誰建立 |
| 「據認為…」 | 指名是誰認為 |
| 「該決定被作出」 | 指名是誰決定 |
| 「問題被解決了」 | 誰解決的？ |

## 歐化語法／翻譯腔

塑膠句抓的是「空洞修飾」，歐化抓的是**句法結構本身像翻譯**。一篇文章可以零塑膠卻整篇歐化。這類毛病在中文寫作裡一般稱為「歐化／西化語法」。

**三秒檢測法：** 把句子念出來。聽起來像翻譯字幕 = 歐化；像人在講話 = OK。

| 歐化模式 | 問題 | 改法 |
|------|------|------|
| 「透過 X，我們可以…」 | 「透過」是台灣 AI 最明顯的水印，整篇刷屏 | 多數可刪或改「用」「靠」「拿」。一篇 ≤ 3 個 |
| 「對於 X 來說 / 對於 X 而言」 | 英文 "for X" 直譯，多半是贅句 | 直接講 X 怎樣，刪掉「對於…來說」 |
| 「在 X 的情況下 / 在 X 的前提下」 | 英文 "in the case of" 句架 | 改「X 時」「如果 X」 |
| 「使得 / 使其」 | 英文 "make it" 直譯 | 改主動句，指名誰讓它怎樣 |
| 「X 之一」（最…之一） | 英文 "one of the" 句架 | 多半可刪「之一」，或直接說 X 怎樣 |
| 「們」濫用（用戶們、工程師們） | 中文不用複數標記，名詞本身已含複數 | 刪「們」 |
| 「進行了一個 X 的動作」 | 英文 "perform an action" 結構 | 直接用動詞 |
| 「具有 X 性 / X 化」堆疊 | 抽象名詞化，英文 "-ity / -ize" 直譯 | 還原成具體動作或形容 |
| 「不僅…而且…」「由於…因此…」成對連接 | 英文 "not only...but also" 「because...so」雙連接詞 | 中文留一個就好，常可全刪 |
| 「一個 / 一種 + 抽象名詞」當主詞 | 英文不定冠詞直譯 | 刪量詞，或換具體主詞 |

**改法總則：** 把句子念出來，凡是「中文不會這樣講」的地方就是歐化點。語意沒錯不代表沒問題——讀者會出戲。

## 節奏與標點

| 模式 | 改法 |
|------|------|
| 三項清單 | 用兩項或一項 |
| 自問立刻自答 | 讓問題留白，或直接刪問句 |
| 每段都用金句收尾 | 換收法 |
| 破折號（——）濫用 | 改用逗號或句號 |
| emoji 當項目符號（✅🔥💡 開頭） | 用一般符號或散文 |
| 連發感嘆號 | 多數情況一個都不用 |
| 句末「呢、啦、喔」過量 | 視文體節制 |

## 用語極端化

| 模式 | 問題 |
|------|------|
| 「所有」「永遠」「從不」「每個人」「絕對」 | 假權威。用具體取代橫掃式宣稱 |
| 「徹底改變」「顛覆」「革命性」 | 行銷腔的誇大，除非真的是 |
