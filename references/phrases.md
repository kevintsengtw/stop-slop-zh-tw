# 要移除的詞語

針對中文 AI 寫作的真實慣用語，不是英文規則的直譯。

## 開場清喉嚨

這些是在講重點前的宣告，砍掉，直接講內容。

- 「眾所周知，」
- 「值得注意的是，」
- 「值得一提的是，」
- 「不可否認，」
- 「毋庸置疑，」
- 「在當今這個 X 的時代」
- 「在數位化的浪潮下」
- 「隨著 X 的快速發展」
- 「首先，讓我們來了解一下」
- 「接下來，我將為你介紹」
- 「讓我們一起來探討」
- 「在開始之前，我們先」
- 「相信大家都」

任何「讓我們 / 接下來我將 / 首先來了解」的起手式，都是上菜前的繞場。刪掉，直接上。

## 強調拐杖

沒有訊息量，刪。

- 「劃重點」
- 「敲黑板」
- 「請注意，這很重要」
- 「這一點至關重要」
- 「這背後的意義不容小覷」
- 「細思極恐」
- 「你沒看錯」
- 「沒錯」（句首單獨使用時）

## 互聯網黑話（同時也是中國用語）

換成白話。這類詞對台灣讀者來說 AI 味與中國味兼具。

| 避免 | 改用 |
|------|------|
| 賦能 | 強化、讓…能夠、幫助 |
| 抓手 | 著力點、方法、切入點 |
| 閉環 | 完整流程、形成循環 |
| 顆粒度 | 細緻程度、粒度 |
| 對齊（顆粒度／認知） | 取得共識、講清楚 |
| 打法 | 做法、策略 |
| 落地 | 實作、實際執行、上線 |
| 心智（用戶心智） | 認知、印象 |
| 拉齊 | 協調一致、同步 |
| 復盤 | 檢討、回顧 |
| 沉澱（經驗沉澱） | 累積、整理留存 |
| 倒逼 | 反過來促使、逼出 |
| 鏈路 | 流程、路徑 |
| 強抓手 | 關鍵著力點 |
| 組合拳 | 一套配套做法 |
| 護城河 | 競爭優勢、門檻 |

## 冗贅動詞結構

中文 AI 愛用「進行 / 做 + 名詞」把動詞架空。直接用動詞。

| 避免 | 改用 |
|------|------|
| 進行優化 | 優化 |
| 進行測試 | 測試 |
| 進行分析 | 分析 |
| 進行討論 | 討論 |
| 做一個 X 的動作 | 直接 X |
| 給予支持 | 支持 |
| 作出貢獻 | 貢獻 |
| 實現 X 的提升 | 提升 X |

## 程度副詞與口語（大陸腔）

- 「特別」（當「非常」用）→ 非常、很
- 「挺 X 的」→ 滿 X 的、蠻 X 的
- 「賊」（賊快、賊好）→ 超、非常
- 「搞」（萬用動詞）→ 指名實際動作（做、處理、弄壞、搞定→完成）
- 「玩兒」「整」（東北腔滲漏）→ 對應實際動作

## 收尾套話

文章該自然結束，不要宣告自己結束。

- 「總而言之」「綜上所述」「總結來說」（放句首當收尾招牌時）
- 「希望這篇文章能幫助到你」
- 「希望對你有所幫助」
- 「如果你覺得有用，別忘了…」
- 「讓我們拭目以待」
- 「未來可期」
- 「路漫漫其修遠兮」（強行文青）

## 空泛宣稱

宣告重要性卻不講那個具體的東西。砍掉，或換成具體內容。

- 「意義重大」
- 「影響深遠」
- 「至關重要」
- 「不言而喻」
- 「其重要性不言而喻」
- 「具有里程碑意義」
- 「是一場深刻的變革」

如果一句話說某事很重要／很深刻，卻沒指出具體是什麼，就刪掉它，或換成那個具體的事。
