# 台灣用語校正（taiwan-md 層）

把中國用語換成台灣慣用語。這是正簡轉換（俗稱繁簡轉換）做不到的——「視頻」轉成正體仍是「視頻」，要的是**詞彙層級**的對應。

對照規則整理自 [taiwan.md](https://taiwan.md) 用語詞庫（CC BY-SA 4.0，超過 3936 條，分 A–F 類）。以下為技術寫作高頻子集；完整資料見 [用語詞庫](https://taiwan.md/terminology) 與 [轉換器](https://taiwan.md/terminology/converter)。

## 使用原則

- **技術名詞優先保留英文。** Agent、MCP、Extension、Hook、Skill、Endpoint、Token、Commit、PR、Repo、Deploy 等不必硬翻。
- **同形詞不要過度校正。** 「框架」「部署」「分支」「序列化」兩岸相同，別改錯。
- **語感層面也要看。** 用語對了，但句法是大陸書面腔（「對…進行賦能」），仍需依 phrases.md / structures.md 處理。
- **完整資料**：本表是高頻子集。需要全量 3936 條規則時，到 taiwan.md 詞庫或用其開源資料（注意 CC BY-SA 4.0 的相同方式分享義務）。
